# Waste Management Executive v5.2

工場実務・工場経営・経営者育成の統合学習サイト。v5.1の機能を維持し「週間まとめ」を追加。

## 週間まとめ
- 保存した学習記録を月曜〜日曜単位で自動表示
- 「印刷・PDF保存」でブラウザの印刷ダイアログを開く（PDF保存を選択可能）
- 「ChatGPTで週報を整える」で当該週の実データを含むプロンプトをコピー
- 同じテーマを複数日に学んでも履歴を残せるよう、保存時にsessionsへスナップショットを追記
- 旧データ（notes）の当該週の記録も表示。古い日付の履歴を捏造・再構成しない

## データと更新
- 既存のlocalStorageキー cbl_v42_state を維持。v5.1以前の記録を削除しない
- 更新前にサイトの「バックアップ」でJSONを書き出すこと
- スマホとPC間ではlocalStorageは同期されない
- 会社情報を含む週報は機密資料として扱う。外部AIに送信する前に内容を確認
