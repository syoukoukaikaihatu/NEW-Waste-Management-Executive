# Waste Management Executive v5.1

廃棄物処理工場のグループ長向け統合学習サイト。工場実務24テーマ、工場経営の実践18テーマに加え、旧 Executive Development Ver.20 Weekly の経営者育成カリキュラム全テーマ（10分野）を統合しました。経営者育成の一般理論を学び、廃棄物処理工場の経営判断に応用します。

## 使い方
1. HOMEで工場実務／工場経営を選択。さらに体系学習が必要なら「経営者育成｜体系学習」を開く
2. ChatGPT用プロンプトをコピー。15〜30分の対話学習を行う
3. ChatGPTの[SITE_DATA]を貼り付け、学習記録・会社の現在地へ保存
4. 必要なテーマだけ「共有資料」ボタンでA4 1枚の資料作成プロンプトをコピー

## データ移行
- 旧廃棄物サイトと同じ localStorage キー `cbl_v42_state` を使用。旧データは上書きしないことを優先
- 旧経営者育成サイトは別ドメイン/別保存キー `exec_simple_v2_records`。ZIPだけでは学習記録は移行できません
- 旧サイトの「学習・分析記録」→「JSONを書き出す」で出力したJSONを、新サイトの「学習記録」→「旧・経営者育成サイトの記録を取り込む」で追加できます
- 旧記録は原文のまま保持。テーマ名が一致する学習記録だけ体系学習に紐付け。分析記録は原文保持し、学習完了扱いにしません
- 新サイトへの更新前に必ず現行サイトからJSONバックアップを出力し、更新後に照合してください
- GitHub Pagesは公開サイト。機密データをソースコードへ埋め込まないでください。localStorageは端末間で同期しません
